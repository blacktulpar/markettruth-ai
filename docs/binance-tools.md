# Binance Agent OS / MCP tool inventory

To be populated from a live Codex + Binance MCP session.

For each useful tool record:

- tool name
- purpose
- required parameters
- output shape
- whether authentication is required
- which MarketTruth specialist uses it

## Minimum data we want for Market Move Autopsy

- ticker / price / 24h change
- candlesticks
- order book
- funding rate
- derivatives metrics exposed by the connected Agent OS environment
- onchain signals exposed by the connected Agent OS / Skills environment
